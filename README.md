# Golden Restaurant 🍽️

A beautiful restaurant landing page built with HTML, CSS & JavaScript.

## Features
- Responsive design for all devices
- Smooth scrolling navigation
- Animated logo and elements
- Menu showcase with hover effects
- Customer reviews section
- Special discount popup

## Technologies
- HTML5
- CSS3 (Custom styling)
- JavaScript
- Google Fonts (Vazir)

## Pages/Sections
- **Home** - Hero section with animated logo
- **Menu** - Food categories with images
- **Reviews** - Customer testimonials
- **About Us** - Restaurant story
- **Contact** - Reservation form & contact info

## How to run
Open https://luppin-1.github.io/Restuarant/ in your browser.
